# WordShift — Data Deletion Request

WordShift is a word puzzle game developed by **Jonathan Pearl Everett**. This page explains how to delete the data WordShift handles. WordShift has no user accounts; data is associated only with a random, anonymous install identifier (not your name, email, or phone number).

## Delete your on-device data

Open **WordShift → Settings → Reset All Progress**. This permanently deletes all local game data on your device — progress, in-game currency (amber), statistics, achievements, settings, and local caches. Uninstalling the app also removes this local data.

## Delete your off-device (cloud) data

WordShift may store the following on our backend, tied only to your random install identifier:

- An optional cloud backup of your game save (only if you used **Settings → Backup & Restore**)
- Daily Challenge leaderboard results (completion time, stars, hints)
- Anonymous analytics events and crash reports

To request deletion of this data, email **jpearleverett@gmail.com** with the subject **"WordShift data deletion."** If you created a cloud backup, include your recovery code (Settings → Backup & Restore → Show recovery code) so we can locate and remove the associated records.

## What is deleted vs. kept

- **Deleted:** your cloud save, your leaderboard entries, and the analytics and crash records associated with your install identifier.
- **Kept:** aggregate, non-identifying totals (for example, the total number of words offered across all players on a given day) that are not linked to you or your device.
- **Advertising identifier:** you can reset or delete it at any time in your device settings (Settings → Ads / Privacy → Ads).

## Retention

We process deletion requests within **30 days** of receipt. Anonymous analytics and crash data is retained for up to **24 months** unless you request earlier deletion.
